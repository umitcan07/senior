Reference Recording Brief

25 short English sentences • recorded once in a single native accent (the dialect agreed for this order)

Recording specifications

  • Format: WAV, mono, 16-bit. Sample rate 16 kHz or 48 kHz (either is fine).
  • One clean take of each sentence. No music, no effects, and please no compression, noise reduction, or EQ — raw, unedited audio.
  • Quiet room, consistent mic distance. A natural, conversational pace — please don't over-enunciate or exaggerate; read each line as if speaking to a friend.
  • You're welcome to record everything in one continuous take. If you do, please pause for a few seconds between sentences. Separating the sentences into individual clips is appreciated but not required.
These lines are used as pronunciation references for language learners, so a relaxed, authentic delivery in your own accent matters far more than a polished or theatrical reading.
